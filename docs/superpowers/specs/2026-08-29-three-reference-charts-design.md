## 5. 读图与定位规范（v1 误读踩坑修复）

**踩坑记录**：第一批次 v1 从样张读数时曾把轴上数字认错（如 6450.9 误读为 6460.9）——整图缩略图上认数字天然不可靠。本批次起执行以下规程：

1. **数值识别——局部放大逐个确认**：轴标签与位阶数字必须放大到局部逐个读取，禁止凭整图视觉认数；
2. **数据交叉验证**：任何图上读出的位阶必须落在该品种数据 min/max 的合理区间内，矛盾即重读（如"目标位"高出数据最高点一截必为误读）；
3. **文字优先**：原报告正文写明的位阶（如 7560/6999.8/6460.9）优先级高于图上读数；
4. **像素→坐标标定**：读取标注位置时，以横/纵轴刻度标签为基准做线性映射（zoom + 刻度锚点），渲染后与样张并排回读比对。

**多图层定位（架构保证，非新增能力）**：所有图层共用同一坐标系——x 为交易日 pos 轴、y 为价格轴，全部原语经同一 `Ctx` 绑定同一对面板轴；圆圈压在压力线上 = 两者共享同一 (x, y)，天然对齐。**图层叠加顺序 = YAML 声明顺序**（蜡烛→均线→通道→标注，后声明在上层），"谁更近"由声明顺序确定性决定。渲染层不存在每图层独立坐标系，也不存在像素定位（像素只出现在读样张阶段）。
